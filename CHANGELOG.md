### [v1.0.0-preview.2](https://github.com/LuluCJJ/time-ledger/releases/tag/v1.0.0-preview.2) · 2026-10-29

- 暖白与浅绿界面、分类图标、左侧分类与右侧时长、紧凑 Flomo 入口。
- 手机底部导航与页签横滑，保留周/月周期切换及周图缩放。
- 周/月分类占比环形图、无备注紧凑卡片、底部切换活动、长计划自动展开。
- 正式包名与签名延续 preview.1；APK 内部版本为 2。与早期试用版仍是独立安装。


### 2026-10-27 · 源码更新，尚未发布安装包

源码：[e821451](https://github.com/LuluCJJ/time-ledger/commit/e821451)。这轮更新已进入公开源码；当前公开 APK 不包含以下变化。

- **界面：**调整首页时间线、当前活动卡和分类标签；将 Flomo 入口收为小按钮，并统一周/月、分类、数据和编辑页面的视觉样式。
- **专注与留白：**在专注页记录当前活动的备注；可按需查看留白提示、当天计划和之前的备注，也可从专注页开始切换下一段。提示不会自动创建活动或增加计时。
- **记录方式：**想法、过程与结果共用当前活动的备注；已有的分类、时间线及备份数据结构保持不变。

## English

### [v1.0.0-preview.2](https://github.com/LuluCJJ/time-ledger/releases/tag/v1.0.0-preview.2) · 2026-10-29

- Warm light surfaces, category icons, left-aligned category headings and a compact Flomo action.
- Mobile bottom navigation and page swipes, retaining period navigation and chart zoom.
- Weekly/monthly category donut charts, compact empty entries, bottom activity controls and expanding daily notes.
- Uses the same official package ID and signing key as preview.1; Android version code is 2. Earlier trial installations remain separate.


### 2026-10-27 · Source update, APK not yet released

Source: [e821451](https://github.com/LuluCJJ/time-ledger/commit/e821451). These changes are in the public source but not in the currently published APK.

- **Interface:** a clearer timeline, current-activity card and category labels; a compact Flomo action; and a consistent visual style across review, category, data and editing screens.
- **Focus and reflection:** write to the current activity's note, optionally revisit reflection prompts, today's plan and previous notes, or switch to the next activity from focus. Prompts do not create activities or add tracked time.
- **Records:** thoughts, progress and outcomes share the existing activity note; the existing category, timeline and backup data structures remain unchanged.

The first public Android preview includes time tracking, daily/weekly/monthly views, a focus clock, reviews, Excel export, JSON backup and optional Flomo integration. [Download and installation notes](https://github.com/LuluCJJ/time-ledger/releases/tag/v1.0.0-preview.1).
