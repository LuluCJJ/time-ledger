# 产品原则与页面职责

时间账以「记录事实 → 看见结构 → 写下判断 → 调整行动」为主线。记录不等于生产力评分；日常、休息、娱乐同样是生活的真实组成。

| 页面 | 第一个问题 | 默认展示 | 进一步操作 |
|---|---|---|---|
| 时间线 | 我现在在做什么，今天发生了什么？ | 当前事项、日期与已记时间段 | 点段编辑；当天计划和总结在时间线后 |
| 本周 | 这周的时间结构与重要内容是什么？ | 七日色块、分类分布、有备注事项速览；无记录时显示起步入口 | 放大周图、展开逐日明细、写总结 |
| 本月 | 哪些周的分配不同？ | 按周概览与分类分布；无记录时显示起步入口 | 展开日历和逐日记录、写总结 |
| 分类 | 我如何给一段时间命名？ | 一级组收拢及各组数量 | 展开二级分类，编辑颜色、层级与归档 |
| 数据 | 我能否带走和恢复记录？ | 可读 Excel、完整 JSON 备份、迁入与恢复 | 表格导出、Flomo 设置、日志与重置收在次级层 |
| 专注 | 这段已过去多久？ | 事项、用时、可选预计结束、完成 | 亮屏、横屏、全屏及其他设置折叠 |

视觉原则：暖白与浅绿用于日常记录，深海绿用于沉浸专注，蓝色表示工作、绿色表示提升、红色表示娱乐；日常用低饱和中性灰。色块颜色对应分类，文字必须有足够对比。首页文案应指向用户正在做的事；“Demo”“交互演示”等研发词不出现在正常使用流。

Android 图标与启动画面使用与专注页相同的深绿、浅底和薄荷色时钟标记；图形由仓库脚本绘制，不使用原 App 或封装框架的默认标志。

数据模型优先保存真实起止时间与原始备注。所有统计从记录推导，统计口径可解释；AI 只可在未来作为可选的解释层，不能悄悄改写账本。

## 当前用户旅程

开始活动并选择分类 → 记录真实起点 → 随时进入专注或补充同一条备注 → 结束并选择下一段 → 从日时间线回看 → 周/月地图与分类环形图观察已记录时间 → 写总结并按需传给 Flomo → 导出 Excel 或完整 JSON。

时间块分类靠左、时长靠右；备注为空时收紧高度，Flomo 是右上角次要操作。时间线底部可直接切换活动；单独结束放在专注设置中。手机主导航位于底部，页面空白处横滑切页签；周/月标题处横滑切周期，图表缩放和表单输入优先处理自身手势。

环形图占比的分母是已记录时间，不代表整个周期；二级分类可展开核对。分类图标辅助文字，不能取代文字。
