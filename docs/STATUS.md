# 当前状态

更新：2026-10-25。本仓库已在 GitHub 公开源码预览，没有公开安装包。手机试用版已经有人用于真实记录；安装包发布仍需完成签名迁移和独立设备验收。

**手机导出最新状态**：用户提供的一份非空完整 JSON 已在独立空账本中成功恢复，重载后记录、分类和日志数量保持一致；这证明该快照可恢复，不证明手机此刻的全部新增记录已包含在内。此前产生的 0 B 文件不是备份。用户报告 v39 的 Excel 可导出且能从手机文件管理器打开；应用内“查看下载文件”会返回应用，无法直接打开或分享。v40 改用系统打开／分享最近导出文件的动作。用户后续截图显示旧导入器把本产品可读 Excel 误认为原时间日志 Excel，提示缺少“事件”表；v41 已识别两种格式并完成本地往返检查。用户反馈 v41 的打开、分享和 Excel 导入预览三项手机操作目前都正常；尚未在手机上确认替换导入或验证完整恢复。

**Windows 包最新状态**：当前本地 x64 包已重新打包，并在全新临时资料下隐藏启动成功，退出码 0；首屏标题、时间线内容及 `ledger://bundle` 页面来源已核对。项目、SheetJS、Capacitor 和 Electron 许可文本也在当前包中核对。独立电脑安装、数据迁移与正式发布包仍待验收。

## 已实现

- 本地时间记录、起止时间修正、相邻记录处理、空档补记与中途切换。空档补记覆盖段间、当天末尾和整天无记录三种情况；中途切换使用分组分类选择。
- 一级／二级分类与颜色管理；日时间线、周月结构、每日计划和日周月总结。
- 基于真实起点的专注时钟；Android 亮屏、横屏和沉浸全屏入口。
- 旧时间日志 XLS／兼容 XLSX 导入预览、本产品可读 Excel 的主要内容恢复、完整 JSON 备份、CSV 导出及主动发送 Flomo。
- Android 调试包与 Windows x64 桌面包可以从源码构建；当前桌面包已在隔离的临时用户资料中通过隐藏窗口首屏检查，包内含最新的本机存储保护改动。
