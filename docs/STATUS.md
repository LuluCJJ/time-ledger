# 当前状态

更新：2026-10-24。本仓库已在 GitHub 公开源码预览，没有公开安装包。手机试用版已经有人用于真实记录；安装包发布仍需完成备份恢复、签名迁移和独立设备验收。

## 已实现

- 本地时间记录、起止时间修正、相邻记录处理、空档补记与中途切换。空档补记覆盖段间、当天末尾和整天无记录三种情况；中途切换使用分组分类选择。
- 一级／二级分类与颜色管理；日时间线、周月结构、每日计划和日周月总结。
- 基于真实起点的专注时钟；Android 亮屏、横屏和沉浸全屏入口。
- 旧时间日志 XLS／兼容 XLSX 导入预览、完整 JSON 备份、CSV 导出及主动发送 Flomo。
- Android 调试包与 Windows x64 桌面包可以从源码构建；当前桌面包已在隔离的临时用户资料中通过隐藏窗口首屏检查，包内含最新的本机存储保护改动。

## 当前验证证据

- 网页模型与导入导出检查：32 项通过，包括异常分类导入拒绝、本机记录不可读时保留原始内容，以及设备写入失败后的状态回退。
- 一份旧 XLS 快照已完成只读字段比对；正式迁移仍须使用最新导出，并与新应用中已产生的记录核对。
- Git 当前树及公开主线历史已运行敏感路径、文本模式和提交邮箱数量检查；主线从干净快照开始，作者与提交者使用 GitHub 隐私邮箱。旧提交的 GitHub 缓存视图可能仍可访问，不能把改写主线等同于彻底清除；相关清理请求已提交 GitHub Support，结果待核。SheetJS 0.20.3 文件与官方发布 SHA-256 一致，许可和归属见 [第三方组件](THIRD_PARTY.md)。提交 `1495216` 的 [GitHub Source checks](https://github.com/LuluCJJ/time-ledger/actions/runs/40048702767) 已通过；每次发布仍须核对当次运行。
- Android 调试包可构建。用户手机上出现过 0 B 的完整备份文件；v36 本地包已验签，导出时先在应用内部暂存内容，并且只有目标文件读回与原内容一致才提示成功，但尚未在手机验证。v36 包含项目、SheetJS 与 Capacitor 许可文本，并把临时拍照文件的共享范围限定在应用图片目录；发布配置在没有密钥时生成未签名 APK，四项签名变量齐全时，一次性测试密钥构建的 APK 已通过 `apksigner` 校验。测试密钥与现有手机调试签名不同，测试包不会发布；正式密钥、手机数据迁移、完整二进制依赖许可审查和安装验收仍待完成。Windows x64 包可以启动并加载时间线。

## 发布前待验收

1. 在当前手机上找到完整备份文件；在隔离环境恢复并核对事件、分类、日志、总结和抽样备注。任何历史导入前先处理旧 App 与新 App 的重叠记录。
2. 真机核对最新版本的空档补记、中途切换、导出、窄屏数据页、专注页及覆盖升级保留数据。
3. 项目原创代码与文档采用 Apache-2.0；仓库为 `LuluCJJ/time-ledger`。公开前已运行文件、历史、图像来源和第三方组件检查；这些检查不能代替后续每次发布时的人工审阅。
4. 确定 Android 正式签名、版本号及试用版数据转移方案。现有试用包是 Android 调试签名，新签名的包不能直接覆盖它。

源码预览已公开并标明上述限制；安装包待签名和数据转移演练后另行发布。详细验收见 [发布验收表](RELEASE_READINESS.md) 与 [发布方案](PUBLICATION_PROPOSAL.md)。
